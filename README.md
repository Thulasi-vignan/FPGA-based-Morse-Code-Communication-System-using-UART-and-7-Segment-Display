# FPGA-based-Morse-Code-Communication-System-using-UART-and-7-Segment-Display
FPGA-based Morse code communication system using Verilog HDL. Encodes dots/dashes, decodes ASCII, and transmits data over UART between two Nexys A7 boards. Includes FIFO buffering and multiplexed 7-segment display output for real-time visualization.
